# Handwritten Digit Recognition using Convolutional Neural Networks (CNN)

## 📌 Project Overview

This project implements a Convolutional Neural Network (CNN) to recognize handwritten digits (0–9) using a custom MNIST image dataset. The complete Deep Learning workflow includes image preprocessing, model development, training, evaluation, prediction, and model saving using TensorFlow and Keras.

---

## 🎯 Objective

- Learn the fundamentals of Convolutional Neural Networks.
- Build a CNN for handwritten digit classification.
- Preprocess image datasets for Deep Learning.
- Train and evaluate a CNN model.
- Save the trained model for future use.

## 📊 Project Workflow

1. Import required libraries
2. Read configuration file
3. Load image dataset
4. Preprocess images
5. Normalize pixel values
6. Split training and testing data
7. Build CNN architecture
8. Train the model
9. Evaluate performance
10. Generate confusion matrix
11. Predict handwritten digits
12. Save trained model

The trained CNN model was evaluated using:

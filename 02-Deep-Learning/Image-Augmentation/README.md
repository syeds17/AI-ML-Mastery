# Image Augmentation using TensorFlow/Keras

## 📌 Project Overview

This project demonstrates Image Augmentation using TensorFlow/Keras. Image Augmentation is a preprocessing technique used in Computer Vision to artificially increase the size and diversity of an image dataset by applying various transformations.

Instead of collecting more images, multiple variations of an existing image are generated, helping Deep Learning models generalize better and reduce overfitting.

---

## 🎯 Objective

- Learn Image Augmentation techniques.
- Generate multiple image variations.
- Improve dataset diversity.
- Prepare images for Deep Learning models.

## 📊 Augmentation Techniques Used

- Rotation
- Width Shift
- Height Shift
- Zoom
- Shear
- Horizontal Flip
- Brightness Adjustment

---

## 🚀 Workflow

1. Import required libraries.
2. Load the input image.
3. Convert the image into an array.
4. Configure `ImageDataGenerator`.
5. Generate augmented images.
6. Save augmented images.
7. Visualize the generated images.

---

## 📈 Benefits of Image Augmentation

- Increases dataset size without collecting new images.
- Reduces overfitting.
- Improves model generalization.
- Enhances robustness against variations in real-world data.

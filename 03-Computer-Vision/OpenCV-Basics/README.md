# OpenCV Basics using Python

## 📌 Project Overview

This project demonstrates the core functionalities of OpenCV for image and video processing using Python. It covers essential image transformations, video playback, live webcam capture, and webcam recording, providing a solid foundation for Computer Vision applications.

---

## 🎯 Objective

- Learn the fundamentals of OpenCV.
- Perform basic image processing operations.
- Understand video and webcam processing.
- Build a foundation for advanced Computer Vision projects.

---

## 🛠 Technologies Used

- Python
- OpenCV (cv2)
- NumPy
- Matplotlib
